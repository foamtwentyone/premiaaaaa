# Лучший трек 2026 — премия-турнир

Сайт-турнир треков в формате The International (Dota 2):

- **Групповой этап — швейцарская система, как на TI**: в каждом туре встречаются треки с одинаковым счётом
  (2-1 против 2-1). Набрал 3 победы — проход, 3 поражения — вылет. При 16 треках это 5 туров и 33 боя,
  у трека максимум 5 боёв; ровно половина проходит в плей-офф. Нужно 8, 16 или 32 трека.
  Следующий тур формируется автоматически, как только закрыты все бои текущего.
  Есть и классический вариант — группы «каждый с каждым».
- **Плей-офф double elimination** — верхняя и нижняя сетка + гранд-финал.
  - Режим **«Как на TI»**: верхняя половина групп стартует в верхней сетке, следующая — в нижней (первый раунд нижней — на вылет).
  - Режим **«Классика»**: все стартуют в верхней сетке, проигравшие падают в нижнюю.
- **Бой** — два трека. Каждый пользователь ставит *каждому* треку оценку от 1 до 10. Дальше проходит трек с более высоким **средним баллом** (при равенстве — тот, кого чаще оценили выше).
- Во время боя оба трека можно слушать: пауза, перемотка, −10 сек, громкость, mute. Одновременно играет только один трек.

Стек: React + Vite, framer-motion (анимации), Firebase (Auth, Firestore, Hosting, опционально Storage).

---

## 1. Создать проект Firebase

1. Откройте <https://console.firebase.google.com> → **Add project**.
2. **Build → Authentication → Get started** → включите провайдеры **Email/Password** и **Google**.
3. **Build → Firestore Database → Create database** (production mode, любой регион, например `eur3`).
4. **Project settings → Your apps → Web (`</>`)** → зарегистрируйте приложение и скопируйте конфиг.

## 2. Настроить проект локально

```bash
npm install
cp .env.example .env.local      # и вставьте значения из конфига
cp .firebaserc.example .firebaserc   # и впишите ID проекта
npx firebase login
```

## 3. Залить правила безопасности и сайт

```bash
npm run deploy     # сборка + firebase deploy --only hosting,firestore
```

Сайт будет доступен по адресу `https://<project-id>.web.app`.

## 4. Стать администратором

1. Зарегистрируйтесь на сайте.
2. В консоли: **Authentication → Users** → скопируйте свой **User UID**.
3. **Firestore → Start collection** `admins` → Document ID = ваш UID, любое поле (например `role: "owner"`).
4. Обновите страницу — в меню появится вкладка **Админ**.

## 5. Провести турнир

1. **Админ → Треки** — добавьте треки: название, артист, аудио и обложку (необязательно).
   - **Аудио (бесплатно):** скиньте mp3 в папку `public/tracks`, перезапустите `npm run dev` и нажмите
     в админке **«Добавить новые»** — название, артист и обложка возьмутся из тегов mp3 (ID3).
     Если тегов нет, название берётся из имени файла вида `Артист - Название.mp3`.
     Файлы выложатся вместе с сайтом при `npm run deploy`. Можно также вставить прямую ссылку на файл
     (Dropbox конвертируется автоматически; Яндекс Диск, ВК и YouTube не подходят).
   - **Обложка:** кнопка «Загрузить обложку» сжимает картинку и сохраняет её прямо в базу — Storage не нужен.
2. **Админ → Турнир** — выберите формат (группы, число групп, TI/классика, размер верхней сетки) и нажмите «Запустить турнир».
   Панель сразу покажет, сколько треков пройдёт в верхнюю/нижнюю сетку и сколько всего будет боёв.
3. **Админ → Бои** — открывайте голосование (по одному бою, целым туром или все готовые), выбрав длительность. По истечении времени голоса перестают приниматься (это проверяют правила Firestore). Нажмите «Закрыть и подсчитать» — победитель посчитается по среднему баллу и автоматически продвинется по сетке.
4. Когда все групповые бои сыграны — **Турнир → Сформировать плей-офф**.
5. После гранд-финала на главной и на странице плей-офф появится победитель и **итоговая таблица мест**:
   места по стадии вылета (гранд-финал → раунды нижней сетки → групповой этап); среди вылетевших на одной
   стадии точное место решает средний балл, общее место («9–11») — только при полной ничьей,
   победы–поражения и средний балл за весь турнир.

Ошибочный результат можно отменить (зависимые бои сетки откатятся) или назначить победителя вручную.

## Загрузка аудио через Firebase Storage (необязательно)

Для новых проектов Storage требует тарифа **Blaze** (pay-as-you-go, есть бесплатная квота).
Если включите Storage (**Build → Storage → Get started**) и укажете `VITE_FIREBASE_STORAGE_BUCKET`, в админке появятся кнопки загрузки аудио и обложек:

```bash
npm run deploy:storage
```

Без Storage просто вставляйте ссылки на файлы.

## Защита от накруток

- Голос — документ `votes/{matchId}_{uid}`: один пользователь = один голос в бою (можно менять, пока бой открыт).
- Голосовать могут только пользователи с подтверждённой почтой (Google-вход подтверждён сразу; при регистрации по почте отправляется письмо).
- Оценки проверяются правилами (целые 1–10), голос принимается только пока бой открыт и не истёк таймер.
- Чужие голоса не видны никому, кроме админа; итоги публикуются при закрытии боя.

## Локальная разработка без реального проекта

```bash
npm run emulators        # эмуляторы Auth + Firestore + Storage (нужна Java)
npm run dev:emulators    # сайт на http://localhost:5173, подключённый к эмуляторам
```

Админа в эмуляторе создайте через Emulator UI (<http://127.0.0.1:4000>): документ `admins/<uid>`.

## Тесты

```bash
npm test    # логика турнира: группы, посев, сетки TI/классика 2–16 треков, откат результатов
```
